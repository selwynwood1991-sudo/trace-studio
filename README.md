# Selwyn’s Trace Studio for Daughter

A simple browser-based AR-style drawing helper.  
It uses a phone’s rear camera and overlays a picture so a child can trace it onto paper.

## How to use

1. Open the app on a phone:  
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

2. Allow camera access when prompted.

3. Place a sheet of paper on a flat surface.

4. Prop the phone above the paper, with the rear camera facing downward.

5. Tap **Choose picture** and select an image from the phone.

6. Drag the image to position it.

7. Pinch to resize it.

8. Twist with two fingers to rotate it.

9. Use the **See-through** slider to make the picture faint enough to trace.

10. Tap **Lock** so the picture stays still while drawing.

11. Trace the outlines onto the paper with a pencil.

## Controls

| Control | What it does |
|---|---|
| Choose picture | Selects an image from the phone |
| Lock / Unlock | Stops or allows movement of the tracing image |
| Outline / Colour | Switches between grayscale and original colour |
| Flip | Mirrors the tracing image |
| Fullscreen | Makes the app fill the phone screen |
| See-through | Changes image transparency |
| Size | Changes the image size |

## Tips

- Use a phone stand, books, or a small tripod to hold the phone steady.
- Start with simple outlines or colouring-book pictures.
- Reduce the image transparency before tracing.
- Use the **Outline** mode for clearer lines.
- If the camera does not start, refresh the page and allow camera permission.

## Browser support

Works best in:

- Chrome on Android
- Safari on iPhone or iPad

Camera access requires a secure HTTPS connection. GitHub Pages provides this automatically.

## Privacy

This app runs entirely in the browser.  
Pictures selected for tracing are not uploaded to a server.
